# Weft downloads

Download the latest [Weft installer for Apple silicon](https://github.com/gauchomatt/weft-updates/releases/latest). Requires macOS 26 or later.

This public repository holds only signed installers and the [automatic update feed](appcast.xml). The Weft source code lives in a separate private repository. To run a project, you will also need that project's checkout, required development tools, and access credentials.
